# Git hook framework
# Declared explicitly on purpose: HA Core ships whichever framework it happens
# to pin, and relying on that silently left script/setup/bootstrap installing
# no hooks at all when the pin moved from pre-commit to `prek` in HA 2026.4.
# #77 switched bootstrap over to prek, so that is what is pinned here now; prek
# reads the same .pre-commit-config.yaml. The pin stays explicit rather than
# transitive through pytest-homeassistant-custom-component, for the same reason
# it always was.
prek==0.4.14

# GitHub Actions workflow auditing (script/yaml-check)

# --offline locally if you have no GH_TOKEN and the online audits stall.
